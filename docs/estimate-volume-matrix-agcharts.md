# AG Charts 帳票グラフ　方式見積もり

## 0. 前提

- 対象はスパイク済みの **AG Charts 帳票**（曼荼羅 transitionNetwork は含まない。別見積: `estimate-scratch.md`）。
- 方式は **AG Charts（Enterprise）一択**。ライセンスは導入済みのため選定・導入検証は含めない。
- 各帳票に参考画像があり、スパイクで実現可否を確認済み。本見積は **本番実装** の工数。
- **1グラフあたりおおよそ 2 週間（約 60h／稼働約 10 日）** を目安とする（単純な棒はやや短め、複合 UI はやや長め）。

工数が抑えられる共通理由:

1. 自前の幾何計算・SVG 描画が不要
2. 参考画像＋スパイクがあり、ゼロからの見た目設計ではない
3. PNG・React ラッパー・画面シェルは既存流用が可能

## 2. 実現機能（共通＋グラフ別）

### 2.1 共通

| 機能 | |
| --- | :---: |
| PNG ダウンロード | ○ |
| PNG クリップボードコピー | ○ |
| スライダー等による件数／サイズ切替（スパイク相当） | ○ |
| ズーム | —（本画面群では不要想定） |

### 2.2 グラフ別（スパイクで確認済みの核）

| グラフ | 核となる表示 |
| --- | --- |
| ボリューム付数表 | 過去×現在マトリクス、バブルサイズ＝行%、格子、注記オーバーレイ、マス数1〜7 |
| 買出入(実績) | 前期→当期 KPI、全体3分割バー、ブランド別流出／流入発散棒、800px |
| ウォーターフォール | 期首＋増減＋期末（totals）、棒上数値、棒数1〜7 |
| ブランド発散棒 | 横棒・正負色分け、ブランド数1〜7、800px |
| 購入者割合／脱落者 | 上:積上棒／下:負の棒、期間数1〜7、凡例、800px |
| 人数構成比 | ブランド別100%積上、Sync（2本以上）、DnD並べ替え、ブランド数1〜8 |

制限事項（代表）:

- ボリューム付数表: セル境界は **数値軸＋crossLines**（カテゴリ軸 gridLine では中心線になる）。注記は HTML オーバーレイ。
- 買出入: 上段・中段は HTML、下段のみ AG Charts（単一チャートオプションでは再現しない）。
- 人数構成比: Sync は `groupId`／再マウント方針に依存。厳密な帳票配置は結合で調整。

## 4. 含めないもの

- 曼荼羅チャート（transitionNetwork／Chord）※別見積
- AG Charts の新規ライセンス契約・社内導入手続き
- 大規模なデザインシステム刷新
- 6グラフ同時リリース時の横断 QA・デザイン統一の一括バッファ（必要なら別枠）

## 5. リスクとバッファ

| リスク | 影響 | 見方 |
| --- | --- | --- |
| 参考画像との細部差 | 各グラフ +4〜8h | 「結合・調整」に一部含む。厳密一致なら上振れ |
| 集計仕様・API 契約の未確定 | BE +4〜12h／グラフ | 契約確定後に再固定推奨 |
| AG Charts メジャー更新差分 | +2〜6h | スパイクは v14 系。本番版固定で抑制 |
| 買出入の HTML＋Charts 分割 | 見た目結合 +4h | 単一チャート化は非推奨（スパイク結論） |

厳しめに見る場合の目安（1グラフ）: **約 60h → 約 72h（約2.5週）**。  
6グラフ連続の場合、単純合算 **350h** に横断調整 **+20〜40h** を見ると安全。
